VETER OPERATING SYSTEM PROJECT

Meet VeterOS.

An independent Linux-based desktop operating system project exploring a clean desktop experience, useful system tools, hardware support and a future home for the wider Veter ecosystem.

View available downloadsExplore the source

🖥️ Desktop experience

Work toward a clear desktop, app launcher, settings, file management and everyday workflows.

⚙️ Hardware support

Explore networking, audio, Bluetooth, display drivers and hardware compatibility across supported machines.

🧩 Veter ecosystem

Long-term direction: bring Veter developer tools and applications into one desktop environment.

Current status: VeterOS is an evolving independent project. Features, device compatibility and installer support depend on the published build. Back up important files and test any ISO in a virtual machine before installing. This page does not claim that every planned feature is available.

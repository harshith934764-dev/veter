THE VETER PROJECT

Meet the Veter programming language

Veter is an independently developed programming-language project created by Chengepally Harshith Reddy. It is being developed around its own language design, .vtr source files, compiler work and learning resources.

What is Veter?

Veter is an evolving language project. Its goal is to make programming approachable through a distinctive syntax and a development environment designed around the language itself. The public repository is the place to inspect the source, follow implementation work and review the current state of the project.

What does a Veter program look like?

The project's published Core 1.0 prototype materials document commands such as remember for storing values and display for output. For example:

remember learner as "Harshith"
display learner

Syntax and supported behavior can change between compiler versions. Use the documentation and examples that match the compiler build you have installed.

What is implemented today?

Veter is under active development. The repository and official documentation describe the current prototype and its compatibility limits. Planned ideas should not be confused with features that are already implemented. Check the technical documentation, language reference and source repository for the latest verified details.

Who is building Veter?

Veter was created by Chengepally Harshith Reddy as an independent programming-language project.

Frequently asked questions

For more answers, visit the Veter programming language FAQ.

Is Veter a programming language?

Yes. Veter is an independently developed programming-language project with its own source-file extension and evolving compiler implementation.

What file extension does Veter use?

The project's source examples use the .vtr extension.

Is Veter a replacement for Python or Java?

Veter is an independent project, not a proven drop-in replacement for established languages. Compare actual supported features, compatibility and performance before choosing a language for a project.

MADE WITH VETER · EXAMPLES

Small programs.
Big ideas.

Explore beginner-friendly examples using the syntax supported by the homepage browser playground. Save a snippet, try it and build from there.

Open live playground

Example gallery

These examples use the educational browser runner subset: make, set, say, show, variables, strings and basic arithmetic.

EXAMPLE 01

Hello, Veter

make name "Veter"
say "Hello from " + name

A first program with a text value and output.

EXAMPLE 02

Quick calculation

make price 120
make quantity 3
make total price * quantity
say total

Use variables and arithmetic to calculate a total.

EXAMPLE 03

Rectangle area

make length 12
make width 5
make area length * width
say area

Calculate area using two dimensions.

EXAMPLE 04

Remainder

make total 17
make groups 5
make left total % groups
say left

Use the remainder operator for simple grouping logic.

EXAMPLE 05

Simple invoice

make item "Notebook"
make price 45
make quantity 4
make total price * quantity
say item
say total

Combine text and numeric values in a tiny invoice.

EXAMPLE 06

Update a value

make score 10
set score score + 5
say score

Change a variable and display the new value.

Know the runner's limits

The browser demo is a small teaching interpreter, not the full C++ compiler. Function, array, loop and condition support varies by compiler version. Check the matching documentation before using advanced syntax.

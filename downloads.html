Build the compiler yourself

The current Core 1.0 compiler README documents this C++20 build path.

01 · Get the source

Download veter_core_1_0.cpp and the sample .vtr file.

02 · Install a compiler

Use a C++20-compatible compiler such as a current g++ toolchain.

03 · Build and run

Build with the command shown in the compiler notes, then run the sample program.

g++ -std=c++20 -Wall -Wextra -pedantic veter_core_1_0.cpp -o veter

For Windows Git Bash, the notes show ./veter.exe veter_core_1_0_test.vtr when the output executable is named veter.exe. See the full build notes before starting.

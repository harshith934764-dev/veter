VERSION-SPECIFIC TECHNICAL GUIDE

Build and run Veter Core 1.0.

This guide follows the compiler source, test program and README currently published in the Veter repository. It covers the Core 1.0 front-end prototype, not every proposed feature in the draft language specification.

Important version note: the repository contains multiple Veter experiments. These instructions apply to downloads/veter_core_1_0.cpp and its matching .vtr test file. They are not instructions for every Veter release or for the separate Veter Studio installer.

1. Get the source files

Open the downloads folder on GitHub. Get these two files:

  • veter_core_1_0.cpp — C++20 compiler source.
  • veter_core_1_0_test.vtr — sample Veter program.

Keep both files in the same working folder.

2. Install a C++20 compiler

The published prototype README uses g++ with C++20. On Windows, one option is the MSYS2 UCRT64 environment with its MinGW-w64 GCC toolchain. Open the UCRT64 terminal after installing the toolchain and check that g++ is available:

g++ --version

On Linux or macOS, use a compatible GCC or Clang C++20 toolchain. Package installation commands depend on your operating system and distribution.

3. Compile the Veter prototype

In the terminal, change to the folder containing veter_core_1_0.cpp, then run the documented build command:

g++ -std=c++20 -Wall -Wextra -pedantic veter_core_1_0.cpp -o veter

On Windows, if your compiler creates an executable named veter.exe, use that filename in the next step.

4. Run a Veter program

Run the included sample file using the executable you just built:

# Linux / macOS / Git Bash when output is named veter
./veter veter_core_1_0_test.vtr

# Windows Git Bash when output is named veter.exe
./veter.exe veter_core_1_0_test.vtr

The sample file demonstrates variable storage, output, a conditional block, a counted loop and a condition-controlled loop. The command forms are listed below.

5. Core 1.0 prototype syntax

Store a value and display it

remember score as 95
display score

remember name as expression stores a value. display expression prints a value.

Update a value

remember score as 95
revise score as score + 5
display score

revise name as expression updates a previously stored value.

Choose a condition

remember score as 72
choose when score >= 50
    display "passed"
else choose
    display "try again"
close choice

The documented block starts with choose when, optionally uses else choose, and ends with close choice.

Repeat a fixed number of rounds

remember n as 1
repeat 3 rounds
    display n
    revise n as n + 1
close cycle

repeat N rounds starts the counted loop and close cycle ends it.

Read input

ask for name
display name

The prototype README documents ask for name for reading a line of input into a variable.

6. Troubleshooting

g++: command not found

Your terminal cannot find the C++ compiler. Install or open a terminal configured with a C++20 toolchain, then check g++ --version.

veter_core_1_0.cpp: No such file

The terminal is in a different folder from the source file. Use cd to move into the folder where you saved the file, or provide the correct path.

veter: No such file

The compile step may not have created the executable in the current folder, or the executable may be named veter.exe. Check the compiler output and folder contents.

unterminated string or unexpected token

Check quotation marks, spelling and the syntax for the exact Core 1.0 prototype. Use the supplied sample program as a known reference.

7. What this prototype does not promise

The Core 1.0 README describes an early prototype that translates the newer readable command forms into the existing compiler instruction pipeline. It is not a stable language release. The published notes call for a more formal grammar, improved diagnostics and automated regression tests.

Do not assume that frontend frameworks, backend servers, databases, package management, production deployment, functions or every feature in the draft specification are available in this prototype.

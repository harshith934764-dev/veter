OFFICIAL LEARNING PATH

Learn to think in Veter.

A practical introduction to Veter source files and the command forms documented in the Core 1.0 prototype. Follow the examples in order and test them with a matching compiler build.

01 · Your first Veter file

Create a file named hello.vtr. Type this program:

display "Hello from Veter!"

Save the file as UTF-8. Run it using a compatible Veter compiler or runtime. The browser playground on the homepage is a separate, limited demonstration.

02 · Store information in variables

The Core 1.0 prototype README documents remember for storing values and revise for updating them.

remember learner as "Harshith"
remember score as 80
display learner
display score

03 · Work with values

Try arithmetic expressions documented by the prototype:

remember first as 10
remember second as 5
remember total as first + second * 2
display total

Use parentheses when you want to make grouping explicit. Check the exact operator and type rules for your compiler release.

04 · Make decisions

Use a condition to choose which block should run:

remember marks as 72
choose when marks >= 50
    display "You passed"
else choose
    display "Try again"
close choice

05 · Repeat work

A counted loop repeats a block a fixed number of rounds:

remember step as 1
repeat 3 rounds
    display step
    revise step as step + 1
close cycle

The prototype README also documents while loops.

06 · Practice plan

Beginner

Print messages, store text and numbers, and combine values.

Problem solving

Use comparisons and conditions to make decisions.

Repetition

Write counted loops and condition-controlled loops.

Build confidence

Save small programs, run tests and read compiler errors carefully.

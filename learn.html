Introduction

What is Veter?

Veter is an independently developed programming-language project. Its goal is to make programming approachable through a clear, distinctive syntax. Veter source files use the .vtr extension.

Language features and tools are evolving. Check the release notes and the included documentation for the exact capabilities of the version you install.

01 · Getting started

Your first Veter program

Create a text file named hello.vtr. Try this small example in a Veter-compatible environment:

make name "Veter Language"
say "Hello from " + name

The example introduces two visible commands:

  • make creates a variable and gives it a value.
  • say displays text or a value.
This is a beginner example based on the syntax shown in the Veter website playground. The browser playground may support only a subset of the native compiler's features.
02 · Syntax

Variables and calculations

Here is a simple arithmetic example:

make first 10
make second 5
make total first + second
say total

Use examples supported by the specific Veter release you have installed. Consult that release's included guide for the full grammar and supported operations.

03 · Source files

What is a .vtr file?

A .vtr file is a Veter source-code file. You can create one with a text editor, save it with the .vtr extension, and open it using a compatible Veter tool or runtime.

A file extension alone does not run a program; you need a compatible compiler, interpreter, or runtime for your platform.

04 · Understand the commands

Read Veter code one line at a time

In the beginner examples on this page, each line is an instruction. Read from top to bottom.

make — create a value

Give a name a value so you can use it later.

make city "Hyderabad"

say — show a value

Display text or the value stored in a variable.

say city

Example: put the ideas together

make name "Veter"
say "Hello from " + name
  1. make name creates a variable called name.
  2. "Veter" is the text stored in that variable.
  3. say displays the greeting.
These are the commands demonstrated by the current website playground. Other commands and advanced language features must be checked against the exact compiler release before being documented as supported.

Questions

Frequently asked questions

What file extension does Veter use?

Veter source examples use the .vtr extension.

Is the browser playground the full native compiler?

No. The browser playground is a web-based demonstration and may implement only a subset of the language. Use the matching native Veter release for native compiler functionality.

Where can I find the latest downloads?

Use the Downloads section on the official Veter website. Check the version and platform before installing.

Is Veter still being developed?

Veter is an evolving project. Features may differ between releases, so refer to the documentation shipped with the version you use.

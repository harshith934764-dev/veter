Important: the browser demo runner currently supports only remember, revise, display and basic arithmetic/string expressions. It does not run the full Veter compiler. Use the Core 1.0 build guide for the native compiler prototype.

Try these commands

  • remember score as 95 — store a value
  • revise score as score + 5 — update it
  • display score — print it
  • Use + - * / % and parentheses in numeric expressions.

Editor shortcuts

  • Tab inserts two spaces.
  • Ctrl/⌘ + S downloads the current .vtr file.
  • Use Open file to load a local .vtr or text file.
  • Choose an example to restore a starter program.

A FUTURE DEVELOPER WORKSPACE

Meet the vision for
Veter Studio.

A focused place to create .vtr projects, understand compiler feedback and manage your work. This page describes the product direction; it is not a claim that the full IDE is already released.

Planned product direction

A workspace made for building

The goal is to keep the beginner experience simple while giving experienced developers useful project tools.

01 / EDIT

Code editor

Syntax highlighting, clean editing, tabs and project-aware navigation.

02 / RUN

One-click execution

Run a project with the selected Veter compiler version and see output clearly.

03 / DIAGNOSE

Helpful errors

Readable diagnostics with file names, line numbers and actionable explanations.

04 / ORGANIZE

Project explorer

Manage source files, folders, assets and project settings in one place.

05 / TEST

Testing tools

Run project tests and inspect results as compiler and test-runner integration matures.

06 / SHIP

Build & package

Explore repeatable build workflows and Windows packaging after the core tools stabilize.

Planned development order

Editor foundation → compiler integration → diagnostics → project management → testing workflow → packaging. Each stage should work before the next one is called complete.

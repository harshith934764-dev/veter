LANGUAGE REFERENCE

Veter syntax, explained.

A practical reference to commands documented by the supplied Veter Core 1.0 prototype. Proposed language-standard features are intentionally not presented as implemented.

1. Source files and comments

Veter source examples use UTF-8 text and the .vtr extension. In the Core 1.0 prototype, a line beginning with # is used for comments in the documented examples.

# This is a comment
remember user_score as 95
display user_score

2. Variables

CORE 1.0 PROTOTYPE README

remember stores a value under a name. revise updates a stored value.

remember score as 95
display score
revise score as score + 5
display score

3. Output and input

display writes a value to the program output. The Core 1.0 README documents ask for name as an input command.

display "Welcome to Veter"
ask for name
display name

Confirm input behaviour in the exact compiler build you are using.

4. Conditions

The prototype README documents choose when, optional else choose, and close choice.

remember score as 72
choose when score >= 50
    display "passed"
else choose
    display "try again"
close choice

5. Loops

The documented prototype includes counted loops and condition-controlled loops. Both use close cycle to close the loop body.

remember count as 1
repeat 3 rounds
    display count
    revise count as count + 1
close cycle
remember count as 1
while count < 5
    display count
    revise count as count + 1
close cycle

6. Operators

The Core 1.0 prototype examples demonstrate arithmetic and comparison operators including +, -, *, /, %, and >=. The full precedence and type rules must be taken from the compiler version's tested specification.

remember total as 10 + 5 * 2
display total

7. Legacy command family

The supplied Core 1.0 README says legacy commands remain available in that prototype, including make, set, say, take, check, otherwise, finish, repeat N times, end repeat and keep. Their exact grammar should be verified against the matching source and tests.

8. Compatibility and status

This page documents prototype behaviour, not a guarantee that every released Veter tool implements every command. The website browser playground currently supports only make, set, say and show with a limited expression evaluator. It is not the native compiler.

For design proposals and future language-standard rules, read the language specification draft. For Core 1.0 implementation notes, read the prototype README.

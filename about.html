About Harshith Reddy

Chengepally Harshith Reddy

Harshith Reddy, whose full name is Chengepally Harshith Reddy, is the founder and creator of Veter Programming Language.

This is the official creator profile for Harshith Reddy and his Veter programming language project.

Veter is an independently developed programming-language project. Its source files use the .vtr extension, and the project includes a compiler, learning materials and developer tools. The language and its ecosystem are evolving; the official website and learning guide describe the currently available features.

The project aims to make software development more approachable and to grow an ecosystem for building software. Future goals are ambitions, not claims that every planned capability is already available.

About Veter Programming Language

Veter is the name of the programming language project created by Chengepally Harshith Reddy. The official website is theveter.in. The learning guide explains the .vtr file format and provides beginner examples.

What does Harshith Reddy work on?

Harshith Reddy works on the design and development of Veter Programming Language and its developer tools. The public project includes the language source code, documentation, examples and Veter Studio, a browser-based coding workspace preview.

Veter uses the .vtr file extension. Its compiler and tools are under active development, so visitors should use the official documentation and GitHub repository for the latest implementation details.

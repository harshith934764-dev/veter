# 🚀 Veter Programming Language

**Build beyond the ordinary.**

Veter is an independently developed programming-language project created to make programming approachable through its own distinctive syntax.

🌐 **Official Website:** https://theveter.in/  
📘 **Learning Guide:** https://theveter.in/learn.html

## ✨ About Veter

Veter is an original programming language project developed under the Veter name. Its source files use the `.vtr` extension.

The goal is to build a simple and approachable programming experience.

## 🧩 Project Resources

- **Official Website:** Visit the Veter website.
- **Learning Guide:** Learn the basics of Veter.
- **Source Code:** Explore this public GitHub repository.
- **Downloads:** Find available project downloads on the official website.

## 💻 Getting Started

1. Visit https://theveter.in/
2. Open the Learning Guide.
3. Read the syntax examples for your installed version.
4. Create a file named `hello.vtr`.
5. Try writing your first Veter program in a compatible environment.

.vtr

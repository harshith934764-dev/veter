## ✨ About Veter

Veter is an original programming language project developed under the Veter name. Its source files use the `.vtr` extension.

The goal is to build a simple and approachable programming experience.

## 💻 Getting Started

1. Visit https://theveter.in/
2. Open the Learning Guide.
3. Read the syntax examples for your installed version.
4. Create a file named `hello.vtr`.
5. Try writing your first Veter program in a compatible environment.

## Core 1.0 compiler tests

The Core 1.0 console compiler has a regression suite. With Python 3 and a C++20 `g++` compiler installed, run from the repository root:

```bash
python tests/test_core_1_0.py
```

The suite covers arithmetic, negative values, comparisons, logical conditions, loops, input, and selected runtime errors. It does not certify every Veter runtime or planned language feature. See [`tests/README.md`](tests/README.md) for details.
